## Перевірка випуску

Обов’язкова наскрізна послідовність: бронювання → погодження → автоматичне завдання → видача → підтвердження → повернення → автоматична перевірка → фото та комплектність → завершення → повторна доступність. Окремо перевірити паралельні сесії, дробові витратні матеріали, межі ролей, вкладення, фінанси, повторний імпорт, повторювані й автоматичні завдання, зміну строків, часові пояси, доставку Push та Snooze. Реліз готовий після серверної і наскрізної перевірки, інструкцій для працівників та плану відновлення.
