## Порядок інтеграції

- PR №7 та №10 залишаються окремими від Web Push. Перед інтеграцією кожного повторно звірити гілки з `main` і перевірити спільний порядок.
- Для Web Push спочатку перевірити й застосувати серверну схему, потім розгорнути воркер і захищений планувальник. Клієнт опублікувати з публічним VAPID-ключем лише після перевірки доставки.
- Видача та автоматичні завдання від рухів залежать від PR №7. Призначення, командні коментарі й вкладення потребують перевірених правил доступу PR №10.
