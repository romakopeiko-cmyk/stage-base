# Попередній перегляд імпорту Stage Base

Інструмент створює локальні HTML і JSON для перегляду. Запускайте його в захищеній робочій теці поза публічним репозиторієм. Посилання показуються текстом. Інструмент не завантажує пов’язані фотографії і не з’єднується з Supabase.

```sh
python -m pip install -r tools/import_preview/requirements.txt
python tools/import_preview/preview.py /path/to/source.pdf /path/to/secured/review
python tools/import_preview/preview.py /path/to/source.xlsx /path/to/secured/xlsx-review
```

- `preview.html` показує всі рядки. `review.html` містить рядки з конкретними проблемами даних. Тип обліку потрібно підтвердити для всіх рядків, де він відсутній.
- `preview.json` містить первинні значення, координати PDF або клітинки XLSX, SHA-256 джерела, нормалізовані десяткові значення та групи повторюваних номерів. `review.json` містить окремий список неоднозначних рядків.
- PDF підтримує дев’ятисторінковий шаблон експорту Stage Show Company. Для іншого макета потрібен профіль із перевіреною геометрією. PDF не містить метаданих книги, формул або прихованих клітинок. XLSX читається по вкладках і зберігає формули як вихідні значення для перевірки.
- Первісна вартість переноситься як вихідне поле без припущень про валюту або вартість одиниці. Порожній номер залишається порожнім. Рядки з кількістю понад одну не класифікуються автоматично як витратні матеріали або комплекти.
- Однакові назви з різними номерами залишаються окремими. Повтор номера та збіг назви з позицією без номера є кандидатами до ручного зіставлення. Рядки автоматично не об’єднуються.

## Етап після перевірки

Перед записом до Stage Base потрібні затверджена відповідність складів і полів, класифікація типів майна, перевірка номерів за чинним каталогом та підтвердження користувача. Для запису потрібна окрема серверна операція з правами на імпорт і фінанси, перевіркою повторного запуску та початковим станом `unverified`. Цей пакет завершується на локальному попередньому перегляді.

Підготовлений україномовний Excel можна відкрити безпосередньо в розділі «Майно потребує уточнення» через «Переглянути пакет імпорту». Застосунок читає аркуші «Каталог», «Первинні дані» та «Підсумок» у браузері. Номери, ключі рядків, посилання і відбиток джерела збігаються з JSON-пакетом. Запис до Supabase відбувається лише після явного підтвердження і перевірки чинних серверних прав. Невідомі формати Excel спочатку проходять локальну підготовку за цією інструкцією.
